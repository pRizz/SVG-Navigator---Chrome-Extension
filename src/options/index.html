About

SVG Navigator adds infinite zoom and panning to SVG files on the web. Open any .svg URL and it takes over the page.

GitHub Chrome Web Store Firefox Add-ons SVG 1.1 spec

Tips

To use it on local files in Chrome, turn on Allow access to file URLs for SVG Navigator on the Extensions page.
